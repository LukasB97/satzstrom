# Security

Do not open a public issue for a vulnerability that could put users or documents at risk. Use
**Report a vulnerability** on this repository's Security tab. If GitHub private vulnerability
reporting is unavailable, email `lukas@lb-engineering.org` instead.

Include the affected version, platform, reproduction steps, and impact. Do not attach confidential
documents unless they are necessary and explicitly requested. No response-time SLA is offered during
the public preview.
