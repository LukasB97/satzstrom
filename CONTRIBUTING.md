# Contributing

Bug reports, documentation improvements, examples, and changes to the public packages are welcome.
Open an issue before substantial work so the intended user experience can be agreed first.

Run `pnpm test` before submitting a pull request. Contributions are accepted under the license of
the files they modify. Contributions are limited to the files and public interfaces present here.

Maintainers may integrate an accepted contribution in a follow-up update with author attribution. A
pull request may therefore be closed as integrated instead of being merged directly.
